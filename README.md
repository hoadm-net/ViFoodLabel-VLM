# ViFoodLabel-VLM

A Benchmark for Zero-Shot Structured Information Extraction from Vietnamese
Food Product Labels. Code and experimental harness for a benchmark paper
evaluating whether
modern Vision-Language Models can perform zero-shot structured extraction —
label photo → field-level JSON — from Vietnamese food product labels,
targeting *Discover Artificial Intelligence* (Springer Nature).

## Overview

- **600** self-photographed Vietnamese food label images, each with
  hand-annotated ground truth across **9 fields** (product name, ingredients,
  additives, warnings, a name/value nutrition table, origin, net weight,
  manufacturing/expiry dates).
- **7 VLMs** across 3 groups — closed frontier, open-source large, and a
  Vietnamese document-specialized model — evaluated zero-shot, no
  fine-tuning.
- **Two headline metrics**: field-level F1, and nutrition *pairing
  accuracy* — whether name/value pairs in bilingual, multi-row nutrition
  tables are matched correctly, not just whether the right numbers appear
  somewhere.
- **Four experimental tiers**: main benchmark (with bootstrap CI and
  McNemar significance testing), prompt sensitivity ablation, synthetic
  perturbation robustness, and a human-coded error taxonomy (Cohen's κ).

## Setup

Requires [`uv`](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env   # fill in OPENROUTER_API_KEY
```

The Vietnamese document-specialized model (Vintern-3B-beta) is self-hosted
separately — see [docs/models.md](docs/models.md#self-hosting-vintern).

## Usage

```bash
# Sanity-check cost before spending anything
uv run main.py benchmark --dry-run

# Try a small id range / a single model first
uv run main.py benchmark --start-id 1 --end-id 3 --models mimo-v2.5

# Full tiers
uv run main.py benchmark
uv run main.py prompt-sensitivity
uv run main.py perturbation
uv run main.py report
```

Every API-calling subcommand (`benchmark`, `prompt-sensitivity`,
`perturbation`) supports `--models`, `--images` or `--start-id`/`--end-id`/
`--limit`, `--force` (bypass cache), `--resume` (report cache coverage before
running), and `--dry-run`. API responses are cached to disk keyed by
`(tier, model, image, condition)`, so any command is safely interruptible
and resumable — re-running never re-purchases an already-cached call. Run
`uv run main.py <subcommand> --help` for the full list per subcommand.
